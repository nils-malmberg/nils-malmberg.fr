Cours de data science & machine learning

J'écris ce cours pour me former sérieusement à la data science et au machine learning, et pour garder une trace structurée de ce que j'apprends. Le principe est simple : tant que je ne sais pas expliquer une notion clairement, c'est que je ne la maîtrise pas. Cette page est le sommaire du parcours ; chaque module est une page autonome.

Le cours compte 22 modules : les douze premiers forment le tronc commun, de l'outillage Python au modèle surveillé en production ; les dix suivants traitent ce que ce tronc laissait de côté — incertitude, temps, données non tabulaires, simulation numérique, budget d'annotation, décision, responsabilité, matériel et théorie.

Le format

Le cours suppose des bases solides en mathématiques et en Python — je ne réexplique ni la syntaxe de base, ni l'algèbre linéaire élémentaire, ni le calcul différentiel. L'effort porte sur ce qui est spécifique à la data science et au ML. Chaque notion suit la même trame :

La trame de chaque notion

  1. Intuition — ce que fait la méthode, en une idée, sans formule.
  2. Formalisme minimal — les équations nécessaires, pas une de plus.
  3. Cas d'usage — sur quel type de problème on la sort réellement.
  4. Avantages / limites — pourquoi la choisir, et quand elle casse.
  5. Code — un extrait minimal qui tourne, quand c'est pertinent.

Les modules sont progressifs mais pas strictement séquentiels. Leur numéro est un identifiant stable, dans l'ordre où je les ai écrits ; l'ordre de lecture conseillé est celui des six parties ci-dessous. Chaque module est autonome et renvoie explicitement aux autres quand une notion y a déjà été traitée.

Travail en cours. Ce cours est écrit au fil de mon apprentissage : certains modules seront enrichis, corrigés ou réorganisés. Les erreurs qui restent sont les miennes — si vous en repérez une, elle m'intéresse.

Références que j'utilise

Le cours n'invente rien : il condense et réorganise. Les sources sur lesquelles je m'appuie le plus souvent :

  • The Elements of Statistical Learning (Hastie, Tibshirani, Friedman) — la référence du ML statistique ;
  • Pattern Recognition and Machine Learning (Bishop) — pour le point de vue probabiliste ;
  • Deep Learning (Goodfellow, Bengio, Courville) et le cours de Karpathy pour les réseaux de neurones ;
  • Gaussian Processes for Machine Learning (Rasmussen & Williams), disponible librement ;
  • Reinforcement Learning: An Introduction (Sutton & Barto) ;
  • Statistical Rethinking (McElreath) et Causal Inference: The Mixtape (Cunningham) pour la statistique et la causalité ;
  • Probabilistic Machine Learning (Murphy), la référence moderne la plus complète ;
  • Bayesian Data Analysis (Gelman et al.) pour l'inférence bayésienne appliquée ;
  • Forecasting: Principles and Practice (Hyndman & Athanasopoulos), libre d'accès, pour les séries temporelles ;
  • Understanding Machine Learning (Shalev-Shwartz & Ben-David) pour la théorie de l'apprentissage ;
  • les documentations officielles (scikit-learn, PyTorch, polars, MLflow), qui sont souvent les meilleurs cours disponibles.

Ongoing project · 2026

Data science & machine learning course

I am writing this course to learn data science and machine learning properly, and to keep a structured record of what I understand. The rule I set myself is simple: if I cannot explain a notion clearly, I do not know it yet.

It now runs to 22 modules. The first twelve are the core track, from Python tooling to a monitored model in production; the next ten cover what that track left out — uncertainty, time, non-tabular data, numerical simulation, label budgets, decision-making, accountability, hardware and theory.

The course itself is written in French. It is personal study material, so I write it in my own language. Switch the language selector to FR to read the modules — the outline below tells you what each one covers.

Format

The course assumes solid mathematics and Python — basic syntax, elementary linear algebra and calculus are not re-explained. Every notion follows the same template: intuition, then the minimum formalism needed, a concrete use case, strengths and limitations, and a short code example when it helps.

Module numbers are stable identifiers in writing order; the suggested reading order is the six-part structure shown on the French page: tooling (1-3), mathematical and statistical foundations (4, 5, 13, 22), method and data (6, 17, 7), model families and domains (8, 14, 15, 9, 10, 16), applications and decisions (11, 19, 18), production and accountability (21, 12, 20).

Course outline

  1. Python foundations, tooling and concurrency
  2. Data and deployment: SQL, NoSQL, Docker, Kubernetes, FastAPI
  3. Numerical toolbox: NumPy, pandas, polars, Dask, frameworks
  4. Math for ML: optimisation, linear algebra, SVD and PCA
  5. Inferential statistics: estimate, test, decide
  6. Data science in practice: from problem to dataset
  7. Classical machine learning
  8. Deep learning
  9. Gaussian processes and Bayesian optimisation
  10. Reinforcement learning
  11. LLMs, embeddings, RAG and adaptation
  12. MLOps: taking a model to production
  13. Probability, Bayesian inference and uncertainty quantification
  14. Time series, signals and time-to-event data
  15. Non-tabular data: text, images, audio, graphs
  16. Machine learning for simulation and engineering
  17. Learning with few labels
  18. From scores to decisions
  19. Search, ranking and recommendation
  20. Fairness, robustness, privacy and security
  21. Scaling up: GPUs, distributed training, performance
  22. Learning theory: why generalisation happens

Main references

  • The Elements of Statistical Learning (Hastie, Tibshirani, Friedman);
  • Pattern Recognition and Machine Learning (Bishop) and Probabilistic Machine Learning (Murphy);
  • Deep Learning (Goodfellow, Bengio, Courville);
  • Gaussian Processes for Machine Learning (Rasmussen & Williams);
  • Bayesian Data Analysis (Gelman et al.) and Statistical Rethinking (McElreath);
  • Forecasting: Principles and Practice (Hyndman & Athanasopoulos);
  • Reinforcement Learning: An Introduction (Sutton & Barto);
  • Understanding Machine Learning (Shalev-Shwartz & Ben-David) and Causal Inference: The Mixtape (Cunningham);
  • the official documentation of scikit-learn, PyTorch, polars and MLflow.
