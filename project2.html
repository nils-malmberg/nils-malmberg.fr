Braket - Simulateur de calculs quantiques

Contexte

Le Projet Braket a été réalisé lors de ma première année à Grenoble INP - Phelma, en collaboration avec trois camarades. L'objectif était de développer un logiciel permettant de simuler des circuits quantiques de manière intuitive.

Réalisation

Nous avons développé un logiciel en C et C++ utilisant la bibliothèque graphique FLTK. Braket offre une interface graphique ergonomique permettant de :

  • Définir un état quantique initial
  • Appliquer des portes quantiques (Hadamard, CNOT, Pauli X/Y/Z, etc.)
  • Visualiser les probabilités associées aux composants de l'état quantique
  • Exporter les résultats de simulation

Objectif pédagogique

Ce logiciel vise à rendre les concepts de la physique quantique accessibles et compréhensibles via une interface intuitive — idéal pour des étudiants découvrant le domaine.

Braket - Quantum Computing Simulator

Context

The Braket project was carried out during my first year at Grenoble INP - Phelma, in collaboration with three classmates. The goal was to develop a user-friendly quantum circuit simulator.

Implementation

We built the software in C and C++ using the FLTK graphical library. Braket provides an ergonomic GUI to :

  • Define initialquantum states
  • Apply quantum gates (Hadamard, CNOT, Pauli X/Y/Z, etc.)
  • Visualize probability amplitudes
  • Export simulation results

Pedagogical Objective

This software aims to make the concepts of quantum physics accessible and understandable through an intuitive interface — ideal for students discovering the field.
