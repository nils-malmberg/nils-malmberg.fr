Le site nils-malmberg.fr

Contexte

Durant ma première année d'école d'ingénieur, j'ai commencé à développer ce site web personnel par passion. Ce projet retrace l'évolution de sa conception depuis ses débuts jusqu'à sa version actuelle.

Version 1 (2022) - Les bases

La première version, simple et basique, combinait principalement HTML avec un peu de PHP, peu de CSS et pas de JavaScript. L'objectif était de me familiariser avec le développement web.

Voir la version 1

Version 2 (2024) - Modernisation à Milan

Pendant mon séjour à Milan, j'ai relevé le défi de reconstruire entièrement le site en un week-end. J'ai utilisé un constructeur de site pour la maquette, puis recodé intégralement en HTML/CSS/JavaScript. Cette version introduit la gestion multi-langues (FR/EN) et des animations JavaScript.

Voir la version 2.1 Voir la version 2.2

Version 3 (2026) - Responsive & refonte (actuelle)

L'objectif principal était de modifier la palette de couleur ainsi que la mise en page du site.
